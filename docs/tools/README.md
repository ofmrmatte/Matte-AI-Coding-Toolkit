# Ferramentas e práticas

Os guias desta pasta cobrem problemas recorrentes no trabalho com agentes. Não é uma checklist de instalação.

- [Quality gates](01-quality-gates.md): critérios objetivos antes de entregar.
- [Browser validation](02-browser-validation.md): mudanças visuais e fluxos de interface.
- [Contexto e documentação](03-context-and-docs.md): APIs, versões e serviços externos.
- [Memória persistente](04-persistent-memory.md): decisões que precisam sobreviver entre sessões.
- [GitHub workflow](05-github-workflow.md): mudanças revisáveis e rastreáveis.
- [MCP strategy](06-mcp-strategy.md): acesso a fontes fora do repositório.
- [Subagentes](07-subagent-orchestration.md): trabalho dividido com fronteiras claras.
- [Release automation](08-release-automation.md): build e publicação repetíveis.

Adote só o que resolve um problema real do projeto atual.
