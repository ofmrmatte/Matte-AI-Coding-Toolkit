# Changelog

## Unreleased

Nenhuma mudança publicada desde `1.0.0`.

## 1.0.0 — 2026-08-31

Primeira versão estável do toolkit.

- documentação prática para quality gates, validação no navegador, contexto, memória, GitHub, MCP, subagentes e release;
- workflows para projeto novo, projeto existente, bug fix, UI, release e code review;
- prompts reutilizáveis para inspeção, implementação, correção, revisão visual e produção;
- templates de `AGENTS.md`, `PROJECT.md`, `ARCHITECTURE.md`, `DECISIONS.md` e `TODO.md`;
- bootstraps PowerShell e Bash que preservam arquivos existentes por padrão;
- exemplo completo em `examples/sample-project/`;
- CI para conferir arquivos obrigatórios, links locais e executar smoke tests dos bootstraps;
- README e playbook revisados para manter o uso direto e evitar processo desnecessário;
- `CONTRIBUTING.md`, template de pull request, licença MIT e atribuição ao projeto original.
