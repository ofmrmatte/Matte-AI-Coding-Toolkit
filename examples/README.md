# Exemplos

Os exemplos daqui não são projetos completos. São recortes de como aplicar o toolkit em tipos diferentes de trabalho sem transformar cada tarefa em um processo gigante.

- [Dashboard web](web-dashboard.md): bug de filtro e período em uma aplicação já existente.
- [Automação desktop](desktop-automation.md): mudança em uma aplicação que controla outro software e precisa preservar isolamento operacional.
- [Portal mobile](mobile-portal.md): correção visual e de safe area em telas responsivas.
- [`sample-project/`](sample-project/PROJECT.md): exemplo preenchido de `AGENTS.md`, `PROJECT.md`, `ARCHITECTURE.md`, `DECISIONS.md` e `TODO.md` para uma aplicação web pequena.

Os três primeiros mostram raciocínio de tarefa. O `sample-project` mostra como fica o contexto persistente depois que o toolkit foi adotado de verdade.
