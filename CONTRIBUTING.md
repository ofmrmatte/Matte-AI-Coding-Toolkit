# Contribuindo

Este repositório é pequeno de propósito. Se quiser propor algo, prefira uma mudança que resolva um problema concreto do fluxo em vez de adicionar mais uma camada de processo.

Antes de abrir PR:

- confira se já existe guia parecido;
- explique qual problema motivou a mudança;
- evite transformar preferência pessoal em regra universal;
- inclua exemplo real ou minimamente reproduzível quando a mudança for de workflow;
- mantenha links internos funcionando;
- preserve a atribuição e a licença.

## Documentação

A documentação é em português. Prompts podem ficar em inglês quando isso fizer sentido para uso direto com agentes.

Tente escrever como documentação de trabalho: menos slogan, mais caso, trade-off e condição de uso.

Se uma prática só funciona em uma stack específica, diga isso.

## Mudanças maiores

Para alterar a estrutura principal, adicionar nova categoria de workflow ou mudar a filosofia de `AGENTS.md`, abra uma issue primeiro. É mais fácil discutir a direção antes de espalhar a mudança por vários arquivos.

## Pull request

Uma PR boa responde três coisas:

1. qual problema existia;
2. o que mudou;
3. como você verificou que os links, exemplos ou instruções continuam corretos.

Não precisa preencher um relatório enorme para corrigir typo.
